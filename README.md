## 📌 About The Project

This repository hosts my personal portfolio website along with an integrated subproject - a classic **Simon Game**. The website is designed to showcase my front-end development skills, list my projects, and provide recruiters with a seamless way to download my resume (CV).

### Key Features:
* **Portfolio:** Fully responsive design (RWD), an "About Me" section, project showcase, and built-in PDF resume download.
* **Simon Game:** Complete game logic built with vanilla JavaScript, featuring event handling, dynamic CSS transitions, and audio feedback.
